## 👋 Sobre mí

Soy un **Ingeniero de Software apasionado por construir software que realmente importa**. Con más de 5 años de experiencia diseñando y desplegando aplicaciones web modernas, escalables y orientadas a resultados, encuentro satisfacción no solo en que el código funcione — sino en que funcione *excepcionalmente bien*.

Me mueve la curiosidad: cada problema es una oportunidad para aprender algo nuevo, y cada línea de código es una decisión de diseño. Trabajo con la misma intensidad en el backend, el frontend y la infraestructura, porque creo que un desarrollador completo entiende el sistema de punta a punta.

> *"El software que vale la pena construir es el que resuelve problemas reales para personas reales."*
